# Tanach Reader — תנ״ך

The whole Tanach with Hebrew (vowels and cantillation), English, Rashi and Ramban; aliyot, haftarot, parsha and seder breaks; a scroll layout and a Mikraot Gedolot–style Pages layout.

A static site: open `index.html` through any web server. All data is in `data/`; `data/manifest.json` lists every file with its size and fingerprint for offline downloads (`sw.js`).
